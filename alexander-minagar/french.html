Behind the interaction

A little more context.

This project uses a Python function and spaCy’s French language model to identify word classes, base forms, grammatical features, and dependency relationships.

A word’s class tells you what kind of word it is. Its role describes how it connects to the rest of the sentence. Automatic analysis can be imperfect, especially with ambiguous or unusual phrasing.

Built with spaCy’s French model ↗. The app does not keep a sentence history.
