Extract the download. Open the folder that directly contains index.html. Keep its folders together: the page links depend on those paths.

Preview the home page

Put the files in GitHub.

  1. Sign in to GitHub and choose New repository.
  2. Name it alexander-minagar, choose Public, enable the README, and create it.
  3. Choose Add file → Upload files. Drag in the extracted files plus the assets and api folders.
  4. Enter a message such as Add portfolio website, then commit to main.

Upload the contents of the extracted folder. The repository's first file list must show index.html, requirements.txt, pyproject.toml, and vercel.json. Uploading only the ZIP or an extra enclosing folder prevents the default setup from finding the site.

The supplied README can replace GitHub's starter README. No GitHub Pages setting is needed because Vercel will host this project.

Import the project into Vercel.

  1. Open vercel.com/new. Sign in or create your personal account and choose the free Hobby plan.
  2. Connect GitHub. Grant Vercel access to the alexander-minagar repository and select Import beside it.
  3. Use the settings below. Keep the provided deployment files in the repository.
  4. Select Deploy. Wait for Ready, then open the production address shown by Vercel.
SettingUse this value
Framework PresetOther

Build CommandEmpty. If an Override switch appears, turn it on and leave the command blank.

The address will look something like https://alexander-minagar.vercel.app. That is an example; use the exact URL Vercel assigns to your project.

Hobby is intended for personal, noncommercial use and has usage limits. You do not need Pro to enable the basic features included here. See Vercel's current plans.

Try the complete experience.

Open each of the three project links from Home. In Flashcards, select a deck, reveal answers, navigate between cards, and finish a session. The end screen offers repeat and shuffle options, another deck, the French analyzer, and Home.

The French page accepts up to 500 characters and sends the sentence to this site's Python endpoint. Enter this example and run the analysis:

Le chat mange une pomme.
WordExpected role in this example
chatSubject: who performs the action
mangeVerb: the action
pommeDirect object: what is eaten

The result table labels individual words. The app uses spaCy's fr_core_news_md 3.8.0 model. Apostrophe variants are normalized internally for parsing while your original sentence is displayed. Automatic labels can still be wrong, even for short sentences.

The first request after inactivity can take longer while the Python function loads the model. A placeholder on the Film page is expected until you add your footage.

Make the film page yours.

Open assets/js/site-content.js. Edit it in a text editor, or open the file on GitHub and select the pencil icon. Replace values while preserving the quotation marks, commas, and braces.

For the simplest video setup, upload the film to your own YouTube or Vimeo account, allow embedding, and set videoUrl to its link. Direct MP4 playback is also supported, but a video platform is more convenient for large footage.

Your film, title, synopsis, role, credits, and production dates were not supplied. The starter text identifies that content as pending. Replace it with real details before presenting the film case study as finished.

Keep the flashcards simple.

The app already contains Film language, French essentials, and Web basics. Visitors choose a deck and study immediately. They do not enter cards, choose settings, create accounts, or save progress.

If you later want different cards, edit assets/js/decks.js as the site owner. Each deck's cards array contains objects with question, answer, and an optional note:

{
  question: "What does bonjour mean?",
  answer: "Hello or good day.",
  note: "A common French greeting."
}

Preserve the surrounding array structure and keep deck IDs unique. Counts update from the data. This app is a simple flashcard project; it does not import Anki packages or perform spaced-repetition scheduling.

Publish your later changes.

Edit the relevant file on GitHub, or upload your changed local files to the same paths, and commit to main. Vercel's Git connection will create a new deployment. Check for Ready before reloading the production website.

Keep image and script filenames consistent, including capitalization. Preserve the api folder and dependency files when uploading an updated copy.

Optional: run it on your computer.

Double-clicking index.html previews the pages and flashcards. To use French analysis locally, install Python 3.12 and open a terminal in the extracted project folder.

macOS or Linux commands
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python serve.py
Windows PowerShell commands
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe serve.py

Open http://127.0.0.1:8000, or the local URL printed in the terminal. Keep the terminal open while testing; press Ctrl+C to stop the server. Installing dependencies requires internet access to download spaCy and its French model.

The local virtual environment, .venv, belongs on your computer. Do not include it in a GitHub upload.

If something needs attention.

The home page returns 404

Check that index.html appears directly in the repository root. In Vercel, use Framework Other, Root ./, and the default Output Directory. Confirm the latest deployment is Ready.

The site has missing styles or images

Upload the complete assets folder with its nested folders. Paths and filename capitalization must match the HTML and configuration.

The French analyzer cannot connect

A page opened as file:// has no Python endpoint. Use your Vercel URL or the local server. On Vercel, confirm api/analyze.py, requirements.txt, and vercel.json were included. Open the deployment's runtime logs for the actual error.

Python or the French model fails to install

Open Vercel's build log and locate the first installation error. Keep the supplied Python version and requirement files intact. A model-download error may indicate the wheel URL was unreachable; confirm that dependency can be downloaded before retrying. Do not substitute a different model package without checking compatibility.

The film will not play

Check the video URL and the provider's embedding/privacy settings. For an MP4, upload the actual file and make sure its name and path match videoUrl. The initial placeholder does not contain your film.

The published site still shows old content

Check that you committed the change to main and that Vercel deployed that commit successfully. Then reload the production URL, not an older preview URL.
